# Audit Report Wizard

Create, schedule and template audit reports.

## Features

- Audit creation and editing
- Reusable templates and library
- Calendar, notifications and team management

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/audit-report-wizard.git
cd audit-report-wizard
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
